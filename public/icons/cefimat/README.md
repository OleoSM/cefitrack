# Iconos CEFIMAT

Set funcional para las vistas de grupos y alumnos.

- Formato: SVG, `viewBox="0 0 24 24"`.
- Estilo: contorno de 2 px, extremos y uniones redondeados.
- Color: `currentColor`; se hereda del texto o del tema.
- Tamaño recomendado: 16 px en tablas, 18 px en botones y 20–24 px en cards.

Ejemplo:

```html
<img src="/icons/cefimat/grupo.svg" width="20" height="20" alt="" />
```

En React, cuando el icono deba heredar color dinámicamente, es preferible usar
el componente equivalente de `lucide-react`. Estos archivos sirven para
documentación, exportaciones, correos o lugares donde no se renderice React.
